# Propose Source Adaptation

Act as the adaptation architect.

Prerequisites:
- source inventory exists;
- source/story graph is reconstructed enough for the requested scope;
- major branch/contradiction risks are recorded.

Read the relevant playbooks and migration artifacts, then:

1. Propose an `adaptation-contract.md` using `templates/migration/adaptation-contract.md`.
2. State the proposed fidelity level, branch policy, chronology policy, dialogue policy, gameplay-mechanic treatment and invented-lore boundary.
3. Classify proposed novel material as:
   - `DIRECT CANON CANDIDATE`
   - `SOURCE-SUPPORTED ADAPTATION`
   - `NOVELIZATION BRIDGE`
4. List every irreversible or high-fidelity-risk decision explicitly.
5. Produce a migration report with the smallest Story Skills promotion set needed for the next drafting horizon.
6. Do not promote canon yet.
7. End at an author approval gate: approve all, approve with amendments, select decisions, or reject.

Do not disguise adaptation inventions as source reconstruction.
