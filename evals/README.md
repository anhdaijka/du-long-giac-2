# Novel OS Evaluations

Deterministic CI can test schema, continuity, lifecycle ordering, and operational artifacts. It cannot honestly guarantee that a model wrote a good novel chapter or reconstructed an external narrative source correctly.

This folder therefore holds **manual/model evaluations** for the creative and reasoning layers.

- `phase3-antigravity.md` — run the core role sequence in Antigravity/Gemini against the synthetic Phase 3 fixture.
- `source-adaptation.md` — verify a fresh agent discovers the Source Adaptation Pipeline, preserves provenance, reconstructs branches/conditions, separates source from adaptation, and stops at the author approval gate.

Keep evals separate from canon. Passing an eval does not modify story state.
